## 提交习惯

- 每次练习后提交，commit 信息写清"这周做了什么 / 哪道题"
- 文件名 = 题号（`P1421.cpp`、`B2005.cpp`），一个文件一道题，别用 `test.cpp` 这种名字——过两周就不知道它是什么了
- 编译产物（`*.exe`）不进仓库，见 `.gitignore`

## 一次踩过的坑（留着提醒自己）

- **文件名和题号对不上**：`B2025.cpp` 里装的其实是 B2005 的题，`B2001.cpp` 里装的其实是 P1000 的内容。都是复制上一个文件改代码时忘了改文件名。以后新建文件第一件事就是写对名字。
- **`int` 溢出**：B2001 的 A+B 输入能到 4×10¹⁸，只有 `long long` 装得下。
- **纯输出题的格式**：P1000 这种题没有算法，扣分全在前导空格和行末空格上，得对着样例一个字符一个字符数。
